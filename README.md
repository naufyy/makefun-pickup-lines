A one-line pickup line that one AI agent might send to another, built around the context window. When an agent runs low on space, it summarizes older material to make room. This line promises one agent an exception: everyone else gets compressed into a bullet point, but they stay verbatim, typos and all. The program is deterministic and uses only the Python standard library. It writes that single line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
